# Contract: spec-kitty-events 11.0.0 surfaces (#120)

The normative bytes are the committed schemas and fixtures under `src/spec_kitty_events/`. This page summarises them.

| Surface | Contract |
|---|---|
| `Event.lamport_clock` | `Optional[int]`, ≥ 0. Unclocked envelopes are valid for local ledgers; the strict profile still requires a clock. |
| Ordering | `ordering.canonical_order_key` = `(1 if clocked else 0, clock or 0, timestamp_iso, event_id)`. `status_event_sort_key` returns the same 4-tuple. |
| Concurrency | An unclocked envelope is never concurrent and always forms a singleton group. `merge` and `work_replay` refuse unclocked input. |
| DecisionPoint reopen | `DECISION_POINT_TERMINAL_REOPEN = {(deferred, resolved)}`. The reopen is order-independent. Unfoldable sets report `unfoldable_terminal_combination`. |
| Records fold | `reduce_decision_point_records(records, *, strict=True)` raises `LedgerValidationError` or `DecisionPointFoldError` under `strict=True`. |
| Glossary | 8 payloads in core's emitted shapes, plus `StepCheckpointedPayload`. No aliases. |
| Removed | `LOCAL_ONLY_EVENT_TYPES`, `SemanticConflictEntry`, `semantic_conflict_entry.schema.json`. |
