# REASONS Canvas: lifecycle-reconciliation-completion

## Requirements
- Mirror the core runtime payloads `SignificanceEvaluatedPayload` and `TimeoutExpiredPayload` (spec-kitty `significance.py:485-522`) and `ResolvedRACIBinding` (`schema.py:79-120`) as public contracts named `SignificanceEvaluated` and `DecisionTimeoutExpired` (WP01).
- Add lifecycle conformance breadth (WP02), the reconciliation doc and the release (WP03).

## Entities
- `RaciRoleBinding`: a new RACI actor model. `RuntimeActorIdentity` is not touched (R1).
- `ResolvedRaciSnapshot`: the typed form of core's untyped `raci_snapshot` dict (D6).
- The two payloads; `significance_score` stays an open object, as in core.

## Approach
- Mirror core by shape only, never by import (C-002). The one deliberate narrowing is that `actor_id` is required and non-empty (R2). Every other field keeps core's types, defaults and validators, including the three provenance rules.

## Structure
- `src/spec_kitty_events/decision_significance.py`, re-exported from `__init__`.
- Schemas generated by `schemas/generate.py`.
- Fixtures under `conformance/fixtures/decision_significance/{valid,invalid}`, registered in the manifest and shipped through `pyproject.toml` package-data.

## Operations
- Validation fails closed: frozen models with `extra="forbid"`.
- Each invalid fixture fails for exactly one cause.
- Valid fixtures carry the `SignificanceScore` that core actually serializes.

## Norms
- Changes are additive only: no existing schema, fixture or test expectation changes.
- mypy --strict, ruff check and ruff format pass; the conformance gate passes; schemas show no drift.
- Mission terminology only.

## Safeguards
- Typing the snapshot must refuse nothing core emits, apart from the R2 narrowing. If it would, escalate (C-007).
- Fixtures must be packaged in the wheel (enforced by `test_wheel_contents`).
- The version bump belongs to WP03 only.
